# Lote Matemática — 78 capítulos com modelo 3D

Base: main após a PR #308. Cada capítulo de Matemática que ainda não tinha modelo espacial recebe um objeto próprio no palco comum (`SpatialStage`): luz de estúdio, perspectiva, faces sombreadas, piso e sombras; câmera por arraste, toque e teclado; "Girar o modelo"; e movimento iniciado pela estudante — percurso próprio (círculo virando senoide, setores formando o retângulo, balança, meia-vida, árvore de contagem…) ou varredura do parâmetro.

Diretrizes de UX consultadas no plugin UI/UX Pro Max: no máximo um ou dois elementos animados por vista, movimento reduzido respeitado, retorno visual em toda interação, alvos de 44 px. Gráficos aparecem como prancha no espaço; o que é tridimensional (cônicas no cone duplo, (a+b)³ em oito blocos, três planos de um sistema, coordenadas no espaço, blocos de base 10, 36 resultados de dois dados) é tridimensional de fato.
