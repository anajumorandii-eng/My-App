# Matrizes e sistemas lineares

Data: 2026-09-20

Cinco capítulos recebem um laboratório de estruturas lineares. Cada controle
mostra uma regra que se mantém e uma consequência que muda, sem usar uma matriz
decorativa para explicar um sistema ou vice-versa.

| Capítulo | Controle | Leitura verificável |
| --- | --- | --- |
| Sistemas de Equações | x testado | o mesmo par satisfaz ambas as equações |
| Tabelas e Matrizes | posição a₂₂ | soma elemento por elemento |
| Multiplicação de Matrizes | primeiro termo da linha | produto linha por coluna |
| Determinantes | coeficiente c | ad − bc e invertibilidade |
| Discussão de Sistemas Lineares | três casos | secantes, coincidentes ou paralelas |
