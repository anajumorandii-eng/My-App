# Laboratório de Álgebra

Data: 2026-09-20

Seis capítulos de Álgebra recebem uma configuração manipulável. A casca é
comum apenas para preservar navegação, foco e contraste; a evidência, o objeto
e a consequência mudam conforme a pergunta do capítulo.

| Capítulo | Controle | Prova que aparece |
| --- | --- | --- |
| Técnicas Algébricas | valor de x | expansão e fatoração têm o mesmo valor |
| Igualdades | raiz candidata | a raiz espúria falha na equação original |
| Desigualdades | ponto de teste | o sinal do produto por intervalo |
| Modelagem Algébrica I | primeiro inteiro | a frase vira x + (x + 1) = 47 |
| Modelagem Algébrica II | reduções de preço | preço × quantidade forma uma receita quadrática |
| Representação Geométrica de Inequações | limite c | a fronteira e o semiplano de x + y ≤ c |

Composição de Funções e Bijeção não entram aqui: embora usem álgebra, seu
objeto de estudo é a transformação entre funções. Elas ficam registradas para
uma família de funções, em vez de receberem uma prancha de fatoração emprestada.
