# Auditoria de cobertura — ENEM 2018–2025

ENEM 2018–2025, aplicação regular impressa, cadernos amarelos, opção Inglês; currículo principal por questão, sem dupla contagem de habilidades secundárias.

**1440 posições; 1430 válidas e 10 anuladas.** 97/105 tópicos do currículo possuem registros. 225/612 capítulos não possuem questão válida classificada neste corpus.

Contagem de registros não comprova variedade de habilidades, precisão editorial ou domínio do estudante. Um item tem um tópico principal; pré-requisitos e habilidades secundárias não são contabilizados novamente. Ausência de item neste recorte não significa ausência no ENEM nem obrigação de ampliar esse tópico.

## Integridade e manutenção

- 0 violações estruturais; 0 grupos com mesmo enunciado e alternativas após normalização; 0 grupos com enunciado idêntico para conferência. Isso não substitui revisão semântica individual.
- 0 classificações divergentes entre o lote de importação alinhado e o banco publicado.
- 784 questões ainda têm classificação de origem lexical automática, sem revisão posterior encontrada nos arquivos editoriais consultados.
- 4 questões permanecem sem capítulo, com ressalva editorial em vez de vínculo artificial.
- 2 classificações curriculares atravessam a área oficial da prova; esses casos exigem evidência, não exclusão automática.
