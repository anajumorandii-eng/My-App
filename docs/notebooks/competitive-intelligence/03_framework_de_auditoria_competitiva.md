# Framework de auditoria competitiva

Avaliar cada produto em uma escala qualitativa baseada em evidência, não impressão.

## 1. Problema central
- Que problema promete resolver?
- Para qual estudante?
- Em qual momento da jornada?

## 2. Modelo de decisão
- Só organiza tarefas?
- Prioriza?
- Explica por quê?
- Consegue dizer “não faça”?
- Usa custo de oportunidade?

## 3. Diagnóstico
- Mede conhecimento ou só pergunta percepção?
- Usa questão real?
- Modela incerteza?
- Identifica pré-requisito?
- Distingue tipo de erro?

## 4. Aprendizagem
- retrieval practice;
- spacing;
- interleaving;
- feedback;
- prática guiada;
- discursiva;
- transferência.

Registrar o mecanismo real, não apenas linguagem de marketing.

## 5. Personalização
- O que de fato muda para cada usuário?
- Conteúdo?
- ordem?
- intervalo?
- dificuldade?
- tipo de intervenção?
- tempo/energia?

## 6. Transparência
- Explica a recomendação?
- Exibe confiança?
- Permite discordar?
- Diferencia dado de inferência?

## 7. Eficiência
- Qual é o menor caminho oferecido para corrigir uma lacuna?
- O produto incentiva estudo útil ou tempo de uso?
- Cria tarefas desnecessárias?

## 8. Avaliação
- Como sabe que houve aprendizagem?
- Acerto imediato?
- retenção posterior?
- transferência?
- desempenho em prova?

## 9. Vestibular
- Há adaptação por banca/fase?
- usa provas oficiais?
- segunda fase?
- redação?
- obras?

## 10. UX
- clareza;
- carga cognitiva;
- número de decisões;
- sensação de controle;
- estados de erro;
- mobile;
- acessibilidade.

## 11. Modelo de negócio
- preço;
- trial;
- lock-in;
- recursos pagos;
- incentivos de retenção.

## 12. Evidência

Para cada afirmação, registrar:
- fonte;
- data;
- screenshot/link quando permitido;
- confiança;
- observado diretamente vs marketing.
