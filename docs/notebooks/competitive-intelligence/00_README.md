# CRIVO | Competitive Intelligence

## Descrição

Análise de produtos, plataformas, EdTechs, sistemas de aprendizagem, aplicativos de estudo, ferramentas de IA e soluções adjacentes.

O objetivo não é copiar concorrentes, mas compreender padrões, oportunidades, falhas recorrentes e espaços de diferenciação do CRIVO.

## Estado atual

O repositório não contém uma base confiável de pesquisa externa de concorrentes. Por isso, este pacote começa por:

- baseline do que o CRIVO já faz;
- diferenciação que o produto pretende defender;
- framework comparativo;
- log para novas análises.

Não inventar recursos ou posicionamento de concorrentes sem fonte verificável.
