# CRIVO | UX Research

## Descrição

Repositório de entrevistas, feedbacks, testes de usabilidade, pesquisas, observações e padrões comportamentais dos usuários do CRIVO.

O objetivo é transformar relatos isolados em evidências de problemas, necessidades, comportamentos e oportunidades, evitando confundir opinião individual com padrão de usuário.

## Estado atual

O repositório contém muita evidência de **comportamento do produto e incidentes de interface**, mas não contém um corpus estruturado de entrevistas de usuários.

Portanto:
- fatos de implementação podem entrar como contexto;
- decisões anteriores podem entrar como histórico;
- não rotular inferências do código como “pesquisa com usuário”.
