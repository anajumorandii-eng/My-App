# Pacote de fontes para os notebooks do CRIVO

Este diretório transforma o repositório do CRIVO em quatro bases de conhecimento separadas para pesquisa e decisão:

1. **CRIVO | Learning Science**
2. **CRIVO | Vestibulares & Assessment**
3. **CRIVO | UX Research**
4. **CRIVO | Competitive Intelligence**

## Regra de evidência

Os arquivos distinguem três classes:

- **FATO DO PRODUTO** — comportamento, dado ou regra que existe no repositório.
- **HIPÓTESE** — interpretação ou princípio que ainda precisa ser validado.
- **LACUNA** — informação que o repositório não contém e que precisa de pesquisa externa ou pesquisa com usuários.

Não trate comentários de código, heurísticas ou pesos internos como evidência científica. O objetivo destes arquivos é tornar explícito o que o CRIVO já faz, por que faz e o que ainda precisa ser comprovado.

## Como usar

Importe cada pasta em um notebook separado. Não misture as quatro bases. Quando adicionar fontes externas, preserve a separação:

- Learning Science: papers, revisões sistemáticas, meta-análises, livros acadêmicos e instituições confiáveis.
- Vestibulares & Assessment: editais, manuais, matrizes, provas, gabaritos e documentos oficiais das bancas.
- UX Research: entrevistas, testes, feedbacks, observações e sínteses de pesquisa.
- Competitive Intelligence: documentação oficial de produtos, avaliações, testes comparativos e análises de mercado.
