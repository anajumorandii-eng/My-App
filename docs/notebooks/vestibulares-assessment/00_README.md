# CRIVO | Vestibulares & Assessment

## Descrição

Base de conhecimento sobre vestibulares, exames, matrizes de competência, estruturas de prova, questões, critérios de avaliação e documentação oficial relevante ao público do CRIVO.

O objetivo é compreender o que é realmente exigido pelas avaliações e conectar o modelo de aprendizagem às demandas concretas das provas.

## Escopo atual do produto

O repositório trabalha com:
- FUVEST;
- Unicamp/Comvest;
- Unesp/Vunesp;
- Famerp;
- Unifesp;
- ENEM.

## Hierarquia de fonte

1. Edital/manual/regulamento oficial.
2. Prova e gabarito/resposta esperada oficial.
3. Página oficial da banca/universidade.
4. Relatório analítico explicitamente identificado.
5. Material reconstruído — sempre marcado como incerto.

## Regra

Não inventar incidência, peso, formato ou critério quando o dado muda por ano. Se a informação for sensível ao ciclo, carregar ano + fonte + nível de confiança.
